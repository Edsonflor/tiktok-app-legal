Privacy Policy

Last updated: November 25, 2026 · Controller: Edson Almeida, individual creator, Brazil · Contact: philomusic13@gmail.com

1. Scope

This policy covers "Novelas de Natal" (the "App"), a private automation tool used by one creator on the creator's own accounts. The App has no users other than its operator, offers no sign-up and does not process personal data of third parties.

2. Google user data the App accesses

When the operator signs in with Google, the App receives only the data covered by the permissions (scopes) the operator explicitly grants on Google's consent screen, such as basic profile information (name, email address) and access to the operator's own files or content in the Google services that were authorized. The App never accesses data of other Google users.

3. How the data is used

Google user data is used only to provide the App's features to the operator: identifying the authorized account and creating, saving or publishing the operator's own content. It is not used for advertising, is not sold, and is not used to train AI or machine-learning models.

4. Sharing

Google user data is not shared with, sold to or transferred to third parties, except where required by law.

5. Storage and protection

OAuth tokens and data are kept in private infrastructure accessible only to the operator (a private n8n automation server and private databases), transmitted over TLS. Secrets are stored as credentials or environment variables, never in public source code.

6. Retention and deletion

Data is retained only while needed to run the App. Access can be revoked at any time at myaccount.google.com/permissions; tokens are deleted when access is revoked. Deletion of any data can be requested at philomusic13@gmail.com.

7. Google API Services User Data Policy

The App's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

8. Changes

Changes to this policy will be published on this page with a new "Last updated" date.
